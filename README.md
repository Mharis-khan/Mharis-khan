## 🧭 About me

I work with business data to answer the question stakeholders actually care about: **"So what should we do?"**
My projects follow the same path every time: clean the data → find the pattern → build the model or dashboard → recommend an action.

- 📊 Building dashboards and reports in **Power BI** and **Excel**
- 🧪 Analysis and modelling in **Python** and **R**
- 🎤 Presenting findings to non-technical audiences
- 💼 Open to: data analyst roles, internships and freelance projects
